# 🥊 쿵쾅 샌드백

사진 속 친구(전신)를 오려낸 '사진 인형'을 다 같이 때리는 웹게임. 맞으면 허리가 꺾이고, 무릎이 풀리고, 팔로 막고, KO되면 뒤로 쓰러져요. 펀치 · 발차기 · 싸대기 · 꿀밤 · 꼬집기 · 딱밤 · 뿅망치 · 간지럼, 그리고 **뎀프시 롤**.

- 주소: https://cheon-jaeryong.github.io/sandbag/
- 같은 링크로 들어온 사람은 모두 한 샌드백을 같이 때립니다(공개 MQTT 중계, 서버·가입·API 키 없음).
- 사진 얼굴은 **비밀 체육관 링크(`#k=…`)를 받은 사람만** 볼 수 있어요. 저장소와 중계 서버에는 암호화된 글자만 올라갑니다.
- 설정 → 얼굴 추가로 아무 사진이나 샌드백 얼굴로 바꿀 수 있어요.

조작: 도구를 고르고 샌드백을 탭/클릭. 꼬집기는 누른 채 끌었다 놓기, 간지럼은 누르고 있기.
🥊 뎀프시: 좌우로 흔들릴 때 탭(끝에서 치면 PERFECT), 게이지가 차면 💥 필살.
PC: 1~8 도구, 스페이스 뎀프시, F/J 훅, N 다음 얼굴.
